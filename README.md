# BKMQB Plugin Marketplace

BKMQB 外部插件的公开静态索引与市场页面。插件源码由各自 GitHub 仓库维护，构建产物
从对应的 GitHub Release 下载。

- 市场索引：[`index.json`](index.json)
- 插件开发模板：<https://github.com/BKMQB-Plugins/plugin-template>
- 插件市场页面：<https://bkmqb-plugins.github.io/marketplace/>

第一版没有服务端和数据库。提交插件时，请修改 `index.json` 并发起 Pull Request。
